# تحويل المنصة إلى تطبيق أندرويد + إشعارات فورية

هذا الدليل مبني على هيكل مشروعك الفعلي (Express + MongoDB + WebSocket عبر `realtime.js`، والواجهة في `public/`). كل خطوة تشير بالضبط للملف/السطر اللي تتعامل معه.

**الفكرة العامة:** WebSocket الحالي يبقى كما هو للتحديث الفوري داخل التطبيق. نضيف طبقة موازية (Firebase Cloud Messaging) تتكفل بالإشعارات وقت التطبيق مغلق أو بالخلفية — وهذا ما لا يقدر عليه WebSocket وحده.

---

## المرحلة أ — تغليف الواجهة بـ Capacitor

### أ.1 التثبيت
داخل مجلد المشروع:
```bash
npm install @capacitor/core @capacitor/android
npm install -D @capacitor/cli
npx cap init
```
عند السؤال:
- **App name**: اسم التطبيق (مثلاً "الرابطة الولائية لكرة القدم الوادي")
- **App ID**: صيغة عكسية فريدة، مثلاً `dz.lwf.eloued`
- **web dir**: اكتب `public`

هذا ينشئ ملف `capacitor.config.json` في جذر المشروع.

### أ.2 نقطة مهمة: التطبيق يحتاج يتصل بسيرفرك الحقيقي
تطبيق Capacitor لا يشغّل Node.js محليًا — هو غلاف يعرض صفحات الويب ويتصل بالسيرفر عبر الإنترنت (نفس ما يفعله المتصفح). يعني سيرفرك (`server.js`) لازم يبقى منشورًا على نفس الاستضافة التي تستخدمها الآن (Render/Railway/إلخ)، وتضبط `capacitor.config.json` ليشير له مباشرة بدل تحميل `public/` محليًا:

```json
{
  "appId": "dz.lwf.eloued",
  "appName": "الرابطة الولائية لكرة القدم الوادي",
  "webDir": "public",
  "server": {
    "url": "https://your-domain.example.com",
    "cleartextTraffic": false
  }
}
```
بهذا الشكل، WebSocket (`wss://your-domain.example.com`) والـ API كلها تشتغل بدون أي تعديل في `public/app.js` أو `public/chat.js`.

### أ.3 إضافة منصة أندرويد
```bash
npx cap add android
npx cap sync
```
هذا ينشئ مجلد `android/` — مشروع Android Studio كامل. تفتحه بـ Android Studio لأول مرة للتأكد أنه يبني بدون أخطاء (Build > Make Project).

## المرحلة ب — إعداد Firebase Cloud Messaging (FCM)

### ب.1 إنشاء مشروع Firebase
1. اذهب إلى [console.firebase.google.com](https://console.firebase.google.com) → **Add project**.
2. داخل المشروع: **Project settings → Cloud Messaging** — تأكد أن API مفعّل (Firebase يفعّله تلقائيًا للمشاريع الجديدة).
3. **Add app → Android**، أدخل نفس `App ID` اللي حطيته في Capacitor (`dz.lwf.eloued`).
4. نزّل ملف `google-services.json` وضعه في `android/app/google-services.json`.

### ب.2 مفتاح الخدمة (Service Account) — يحتاجه السيرفر لاحقًا
**Project settings → Service accounts → Generate new private key**. يعطيك ملف JSON — احتفظ فيه بأمان، هذا هو اللي يخوّل سيرفرك يرسل إشعارات (لا يُرفع أبدًا على Git — أضفه لـ `.gitignore`).

### ب.3 مكوّن الإشعارات في Capacitor
```bash
npm install @capacitor/push-notifications
npx cap sync
```
في `android/app/build.gradle` تأكد من وجود:
```gradle
apply plugin: 'com.google.gms.google-services'
```
(الغالب Capacitor يضيفه تلقائيًا عند `cap sync` بعد وضع `google-services.json`).

### ب.4 طلب الإذن والحصول على التوكن (كود جافاسكريبت — يضاف لواجهتك)
أضف ملف جديد `public/push.js` (أو داخل `app.js` مباشرة) يُحمّل فقط عند تشغيل التطبيق داخل Capacitor:

```javascript
// public/push.js
(function(){
  if(!window.Capacitor || !window.Capacitor.isNativePlatform()) return; // نتجاهله في متصفح الويب العادي

  const { PushNotifications } = window.Capacitor.Plugins;

  async function registerPush(){
    const perm = await PushNotifications.requestPermissions();
    if(perm.receive !== "granted") return;
    await PushNotifications.register();
  }

  PushNotifications.addListener("registration", async (token) => {
    // نرسل التوكن للسيرفر مرتبطًا بحساب المستخدم الحالي (بعد تسجيل الدخول)
    try{
      await api("/chat/push/register-token", {
        method: "POST",
        body: JSON.stringify({ token: token.value, platform: "android" }),
      });
    }catch(e){ console.error("push token register failed", e); }
  });

  PushNotifications.addListener("pushNotificationActionPerformed", (action) => {
    const data = action.notification.data || {};
    if(data.conversationId){ go("chat"); /* ثم افتح المحادثة data.conversationId */ }
    else if(data.announcementId){ go("announcements"); }
  });

  // استدعِها بعد نجاح تسجيل الدخول (مثلاً في نفس المكان اللي تحفظ فيه الجلسة)
  window.registerPushNotifications = registerPush;
})();
```
استدعِ `window.registerPushNotifications && window.registerPushNotifications()` مباشرة بعد نجاح تسجيل الدخول في `app.js` (حيث تُحفظ الجلسة حاليًا).

أضف `<script src="push.js"></script>` في `index.html` بعد `app.js`.

## المرحلة ج — السيرفر: تخزين التوكنات وإرسال الإشعارات

### ج.1 تخزين التوكن
`db.js` عندك يستخدم وثيقة واحدة بها `users, applications, ... conversations, messages, announcements`. أضف مصفوفة جديدة `pushTokens` لنفس الوثيقة:

في `db.js`، دالة `defaultData()`:
```javascript
function defaultData() {
  return { users: [], applications: [], requests: [], conversations: [], conversationMembers: [], messages: [], announcements: [], pushTokens: [] };
}
```

endpoint جديد في `routes/chat.js` (أو ملف جديد `routes/push.js`):
```javascript
// routes/push.js
const router = require("express").Router();
const db = require("../db");
const auth = require("../middleware/auth");

router.post("/register-token", auth, async (req, res) => {
  const { token, platform } = req.body;
  if (!token) return res.status(400).json({ error: "التوكن مطلوب." });
  const data = await db.getAll();
  data.pushTokens = data.pushTokens || [];
  // نتجنب التكرار: نفس التوكن لا يُخزَّن مرتين، ونحدّث صاحبه إذا تغيّر
  data.pushTokens = data.pushTokens.filter((t) => t.token !== token);
  data.pushTokens.push({ userId: req.user.id, token, platform: platform || "android", updatedAt: new Date().toISOString() });
  await db.saveAll(data);
  res.json({ ok: true });
});

module.exports = router;
```
وفي `server.js` (بجانب باقي `app.use("/api/chat", ...)` إلخ):
```javascript
app.use("/chat/push", require("./routes/push"));
```
(عدّل المسار حسب نمط بقية الـ routes عندك في `server.js`.)

### ج.2 تثبيت firebase-admin
```bash
npm install firebase-admin
```
أضف متغير بيئة جديد في `.env` وفي إعدادات الاستضافة: يحتوي محتوى ملف الـ Service Account (كنص JSON كامل، أو كملف منفصل حسب طريقة النشر عندك):
```
FIREBASE_SERVICE_ACCOUNT_JSON={"type":"service_account", ...}
```

أنشئ ملف `push.js` في جذر المشروع (بجانب `realtime.js`):
```javascript
// push.js — إرسال إشعارات Firebase Cloud Messaging
const admin = require("firebase-admin");
const db = require("./db");

let initialized = false;
function ensureInit() {
  if (initialized) return;
  const raw = process.env.FIREBASE_SERVICE_ACCOUNT_JSON;
  if (!raw) { console.warn("FIREBASE_SERVICE_ACCOUNT_JSON غير معرَّف — الإشعارات معطّلة."); return; }
  admin.initializeApp({ credential: admin.credential.cert(JSON.parse(raw)) });
  initialized = true;
}

async function sendPushToUsers(userIds, title, body, data = {}) {
  ensureInit();
  if (!initialized) return;
  const all = await db.getAll();
  const tokens = (all.pushTokens || [])
    .filter((t) => userIds.includes(t.userId))
    .map((t) => t.token);
  if (!tokens.length) return;

  try {
    const response = await admin.messaging().sendEachForMulticast({
      tokens,
      notification: { title, body },
      data: Object.fromEntries(Object.entries(data).map(([k, v]) => [k, String(v)])),
    });
    // نزيل التوكنات الميتة (تطبيق أُزيل أو التوكن انتهت صلاحيته)
    const dead = [];
    response.responses.forEach((r, i) => { if (!r.success) dead.push(tokens[i]); });
    if (dead.length) {
      all.pushTokens = (all.pushTokens || []).filter((t) => !dead.includes(t.token));
      await db.saveAll(all);
    }
  } catch (e) {
    console.error("push send error:", e.message);
  }
}

module.exports = { sendPushToUsers };
```

### ج.3 الربط بحدث "رسالة جديدة" — `routes/chat.js`
عندك حاليًا (حوالي السطر 573):
```javascript
realtime.sendToUsers(memberIdsOf(fresh, conv.id), "message:new", serialized);
```
أضف فورًا بعده استدعاء الإشعار (فقط للأعضاء غير المتصلين حاليًا، لتفادي إشعار مزعج لمن يشاهد المحادثة فعلًا):
```javascript
const push = require("../push");
const recipients = memberIdsOf(fresh, conv.id).filter(
  (id) => id !== req.user.id && !realtime.isOnline(id)
);
if (recipients.length) {
  push.sendPushToUsers(
    recipients,
    conv.name || "رسالة جديدة",
    serialized.text ? serialized.text.slice(0, 80) : "📎 مرفق جديد",
    { conversationId: conv.id }
  );
}
```
كرّر نفس الإضافة عند السطر ~688 (تعديل ثانٍ لإرسال رسالة، إن كان مسارًا منفصلًا لنفس الحدث).

### ج.4 الربط بحدث "إعلان جديد" — `routes/admin.js`
حاليًا لا يوجد أي بث فوري عند نشر إعلان. أضفه في مسار النشر (السطر 469):
```javascript
router.post("/announcements/:id/publish", async (req, res) => {
  const data = await db.getAll();
  const a = findAnnouncement(data, req.params.id);
  if (!a) return res.status(404).json({ error: "الإعلان غير موجود." });
  a.status = "published";
  if (!a.publishedAt) a.publishedAt = new Date().toISOString();
  a.updatedAt = new Date().toISOString();
  await db.saveAll(data);
  res.json({ announcement: a });

  // إشعار كل الحكام (role === "referee") بالإعلان الجديد
  const push = require("../push");
  const refereeIds = data.users.filter((u) => u.role === "referee").map((u) => u.id);
  if (refereeIds.length) {
    push.sendPushToUsers(refereeIds, "إعلان جديد", a.summary || a.title, { announcementId: a.id });
  }
});
```
(بما أن `res.json` تُرسل قبل الإشعار، هذا لا يبطئ استجابة لوحة التحكم للمشرف.)

## المرحلة د — البناء والنشر

### د.1 بناء APK للتجربة
```bash
npx cap sync
npx cap open android
```
من Android Studio: **Build → Build Bundle(s)/APK(s) → Build APK(s)**. ثبّت الـ APK الناتج على هاتف حقيقي (وليس محاكي فقط) لتجربة الإشعارات وقت التطبيق مغلق فعليًا.

### د.2 التوقيع والنشر على Google Play
- Android Studio: **Build → Generate Signed Bundle/APK** → تنشئ keystore جديد (احتفظ به بأمان تام، فقدانه يمنعك من تحديث التطبيق لاحقًا).
- أنشئ حساب Google Play Console (رسوم تسجيل لمرة واحدة) وارفع ملف الـ AAB الموقّع.
- إذا تفضّل عدم النشر على المتجر مبدئيًا، يمكنك توزيع الـ APK مباشرة (تثبيت يدوي) بدون Google Play إطلاقًا.

## ملخص سريع لما تعدّله بالضبط

| الملف | التعديل |
|---|---|
| جذر المشروع | `capacitor.config.json` جديد + مجلد `android/` |
| `public/index.html` | إضافة `<script src="push.js">` |
| `public/push.js` | جديد — تسجيل التوكن + التعامل مع الضغط على الإشعار |
| `public/app.js` | استدعاء `registerPushNotifications()` بعد تسجيل الدخول |
| `db.js` | إضافة `pushTokens: []` في `defaultData()` |
| `routes/push.js` | جديد — استقبال وتخزين التوكن |
| `server.js` | `app.use("/chat/push", require("./routes/push"))` |
| `push.js` (جذر المشروع) | جديد — دالة `sendPushToUsers` عبر firebase-admin |
| `routes/chat.js` | استدعاء `sendPushToUsers` بعد بث `message:new` (~س573، ~س688) |
| `routes/admin.js` | استدعاء `sendPushToUsers` داخل مسار `/announcements/:id/publish` (~س469) |

**ملاحظة مهمة:** كل هذا لا يمسّ تجربة المستخدمين على المتصفح العادي (الموقع يبقى يشتغل بنفس الطريقة تمامًا) — الإضافات كلها مشروطة بوجود Capacitor (`window.Capacitor.isNativePlatform()`) أو بوجود توكن مسجَّل.
